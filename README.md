# ⚡ SETT VPN

**Free VPN client for Windows** — auto-fetches free server configs, connects via embedded **v2ray-core**, and exposes a **SOCKS5** proxy. Dark minimalist UI, no installation required.

## ✨ Features

- **⚡ One-click connect** — automatically picks the server with the lowest ping
- **🔄 Auto-updating servers** — pulls fresh configs from free sources on every run
- **📦 Self-contained** — v2ray-core embedded, no installation required
- **🖥️ Dark UI** — minimalist WPF interface with custom title bar and lightning icon
- **🔀 Manual selection** — list all reachable servers with latency and pick one
- **🛡️ System proxy toggle** — enable/disable SOCKS5 system-wide in one click

## 🚀 Quick Start

1. Download `SettVPN.exe`
2. Double-click it — no admin rights required
3. Click **CONECTAR (MENOR PING)**
4. Point your browser to the SOCKS5 proxy (see below)

> ⚠️ **First run:** Windows may show _"Unknown publisher"_ (unsigned binary). Click **More info → Run anyway**.

## 🌐 Browser Setup

SETT VPN exposes a **SOCKS5** proxy at `127.0.0.1:10808`.

| Setting    | Value                          |
| :--------- | :----------------------------- |
| Type       | SOCKS5                         |
| Server     | `127.0.0.1`                    |
| Port       | `10808`                        |
| Remote DNS | **Enabled** (avoids DNS leaks) |

Recommended: [SwitchyOmega](https://chrome.google.com/webstore/detail/proxy-switchyomega/padekgcemlokbadohgkifijomclgjgif) (Chrome/Edge).

## ⚙️ How It Works

1. Downloads configs from free public sources (see [Server Sources](#-server-sources))
2. Parses `vless://`, `ss://`, `trojan://`, `vmess://` links
3. Pings each server over TCP and sorts by latency
4. Generates a v2ray outbound config and launches the embedded `v2ray.exe`
5. v2ray listens on SOCKS5 `127.0.0.1:10808`

The `.exe` is **fully self-contained** — the PowerShell scripts under `Core\` and the v2ray binary are compiled into it and extracted to `%TEMP%\SettVPN` on first run. Nothing else needs to be downloaded. The source under `Core\` is exactly what gets embedded, so the app stays fully auditable.

> `v2ray.exe` is **not committed** to the repo. `build.ps1` downloads it from the official [v2fly/v2ray-core](https://github.com/v2fly/v2ray-core) release at build time, keeping the repository small.

```

Core\
  SettVPN_Full.ps1     core logic (parsing, v2ray process, ping) — embedded at build
  SettVPN_Gui.ps1      WPF interface — embedded at build

```

## 🧩 Server Sources

Configs are fetched from free public lists:

- [abc-configs](https://github.com/FreeFolksOn/abc-configs-free-vpn-proxy-list)
- [Pawdroid Free-servers](https://github.com/Pawdroid/Free-servers)

Embedded core: [v2fly/v2ray-core](https://github.com/v2fly/v2ray-core) (v5.53), downloaded by `build.ps1` at build time.

---

## ⚠️ Important

- **Free servers are unreliable.** Configs change or go offline frequently — the app auto-refreshes, but expect occasional failures.
- **Use at your own risk.** Public config lists may contain servers operated by unknown third parties. Don't send sensitive data through untrusted nodes.
- **Antivirus false positive?** The launcher spawns `powershell.exe` hidden, which some AVs flag. The code is 100% open source — see the scripts under `Core\`.
